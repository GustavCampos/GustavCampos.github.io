PegaFila
Queue management system focused on the Notary Office of Ijuí.
The system was created to address challenges such as the need to improve queue management and reduce customer wait times.
Technical issues like the use of printers on the backend and the secure operation of the server locally were also addressed, leveraging existing PCs running Windows. Sistema de gerenciamento de filas focado no Cartório de Ijuí.
O sistema foi criado para resolver desafios como a necessidade de melhorar o gerenciamento das filas e reduzir o tempo de espera dos clientes.
Também foram abordadas questões técnicas, como o uso de impressoras no backend e a operação segura do servidor localmente, aproveitando os PCs existentes com sistema operacional Windows.

SusCube
A comprehensive data analysis of the Brazilian Unified Health System (SUS) was conducted using data cubes, OLAP, and concepts from Big Data, Analytics, and Metrics.
The process included the creation of tools to automate the extraction of DATASUS data via the command line and the conversion of legacy data formats into modern, analysis-ready structures, enabling efficient and scalable exploration of health-related datasets. Uma análise abrangente dos dados do Sistema Único de Saúde (SUS) utilizando cubos de dados, OLAP e conceitos de Big Data, Analytics e Métricas.
O processo incluiu a criação de ferramentas para automatizar a extração de dados do DATASUS via linha de comando e a conversão de formatos legados para estruturas modernas e prontas para análise, permitindo uma exploração eficiente e escalável dos conjuntos de dados relacionados à saúde.
