PegaFila
Queue management system focused on the Notary Office of Ijuí.
The system was created to address challenges such as the need to improve queue management and reduce customer wait times.
Technical issues like the use of printers on the backend and the secure operation of the server locally were also addressed, leveraging existing PCs running Windows. Sistema de gerenciamento de filas focado no Cartório de Ijuí.
O sistema foi criado para resolver desafios como a necessidade de melhorar o gerenciamento das filas e reduzir o tempo de espera dos clientes.
Também foram abordadas questões técnicas, como o uso de impressoras no backend e a operação segura do servidor localmente, aproveitando os PCs existentes com sistema operacional Windows.

SusCube
A comprehensive data analysis of the Brazilian Unified Health System (SUS) was conducted using data cubes, OLAP, and concepts from Big Data, Analytics, and Metrics.
The process included the creation of tools to automate the extraction of DATASUS data via the command line and the conversion of legacy data formats into modern, analysis-ready structures, enabling efficient and scalable exploration of health-related datasets. Uma análise abrangente dos dados do Sistema Único de Saúde (SUS) utilizando cubos de dados, OLAP e conceitos de Big Data, Analytics e Métricas.
O processo incluiu a criação de ferramentas para automatizar a extração de dados do DATASUS via linha de comando e a conversão de formatos legados para estruturas modernas e prontas para análise, permitindo uma exploração eficiente e escalável dos conjuntos de dados relacionados à saúde.

TEG to PVEG prediction Previsão de TEG para PVEG
A web application developed to present the results of a comparative environmental analysis between thermoelectric power plants and photovoltaic panels.
Through interactive visualizations and automated calculations, the application allows users to compare the pollution levels of fossil fuel-based energy with the cleaner alternatives offered by solar generation. Aplicativo web desenvolvido para apresentar os resultados de uma análise comparativa do impacto ambiental entre usinas termoelétricas e painéis fotovoltaicos.
Por meio de visualizações interativas e cálculos automatizados, o aplicativo possibilita a comparação entre os níveis de poluição da geração de energia com combustíveis fósseis e as alternativas mais limpas fornecidas pela energia solar.

Analysis of animated media Análise de mídias animadas
Dashboard developed to analyze the evolution and the sociocultural and economic aspects of the animation industry in the global audiovisual landscape.
The panel presents consolidated data on the production, distribution, and popularity of animations, aiming to answer questions about historical growth, profitability, diversity of occupations involved, and stigmas associated with the genre.
The analysis served as the final project for a data engineering training program. Dashboard desenvolvido para analisar a evolução e os aspectos socioculturais e econômicos da indústria de animações no cenário audiovisual global.
O painel apresenta dados consolidados sobre a produção, distribuição e popularidade de animações, com o objetivo de responder questões sobre crescimento histórico, lucratividade, diversidade de ocupações envolvidas e estigmas associados ao gênero.
A análise serviu como entrega final de um programa de formação para engenharia de dados.

PegaFila 2.0
Complete overhaul of the system developed for the Ijuí Registry Office.
The new application is designed to simplify the implementation of queue management for small and medium-sized businesses, eliminating the need for complex infrastructure.
The entire process is handled directly through the web-based application, offering convenience and low adoption costs. Reformulação completa do sistema criado para o Cartório de Ijuí.
A nova aplicação é projetada para facilitar a implementação do controle de filas em negócios de pequeno e médio porte, eliminando a necessidade de infraestruturas complexas.
Todo o processo é conduzido diretamente pela aplicação, acessível via web, oferecendo praticidade e baixo custo de adoção.
PoTION
Educational platform gamified through tabletop RPG systems.
The platform offers character creation, interactive tools for classroom engagement, and collaborative features for lesson planning, empowering teachers and enhancing the learning experience through creativity and immersion. Plataforma educacional gamificada inspirada em sistemas de RPG de mesa.
A solução oferece criação de personagens, ferramentas interativas para uso em sala de aula e recursos colaborativos para o planejamento didático entre professores, promovendo engajamento e criatividade no processo de ensino-aprendizagem.
